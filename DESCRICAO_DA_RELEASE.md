# Clown Town Tarot — DLC v1.0

78 cartas para o plugin Arcana II (KOReader).

**Instalação:** no Arcana II 6.2.42+, abra **Explorar Cartas → Clown Town Tarot → Baixar**. Depois as cartas funcionam offline.
