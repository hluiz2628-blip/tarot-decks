# Arcana II — Baralhos adicionais

Este repositório distribui **DLCs opcionais** de baralhos para o plugin KOReader **Arcana II**.

- Aplicativo principal: https://github.com/hluiz2628-blip/tarot.koplugin
- DLC Clown Town Tarot: [Release clown-tarot-v1](https://github.com/hluiz2628-blip/arcana-decks/releases/tag/clown-tarot-v1)

## Clown Town Tarot

Baralho original criado por **Yve Lepkowski** (Stolen Thyme), disponibilizado sob **Creative Commons Attribution–ShareAlike 4.0 International** (CC BY-SA 4.0).

- Fonte original: https://stolen-thyme.com/downloads/
- Licença: https://creativecommons.org/licenses/by-sa/4.0/
- Adaptações técnicas: redimensionamento, conversão PNG → JPEG e padronização dos nomes das cartas para KOReader. As adaptações das imagens continuam sob CC BY-SA 4.0.

O ZIP desta DLC contém 78 cartas JPG e o arquivo `LICENSE_CLOWN_TAROT.txt` com créditos e licença. Não é um aplicativo independente. **Não** instale as imagens como `*.koplugin`.

## Uso

No Arcana II 6.2.42 ou posterior, acesse **Explorar Cartas → Clown Town Tarot → Baixar**. A internet é necessária somente durante o download; depois as imagens funcionam offline.
